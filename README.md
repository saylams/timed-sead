# timed-sead
Instances, models and code for scheduling timed suppression of enemy air defences (SEAD) with manned aircraft and drones: continuous-time and time-indexed MILP formulations (Gurobi), instance generator and solution checker.

Status of the paper: Under Review
The source code, pretrained models, and evaluation scripts are currently being finalized for public release and will be uploaded here immediately upon publication.
